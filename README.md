# Numerical analysis coursework

Computational work from the Numerical Analysis course at Northeastern University. The repository collects notebook-based exercises covering approximation, numerical linear algebra, differential equations, optimization, eigenvalue methods, and related scientific-computing topics.

## How to use this repository

Each HW##/ directory contains the notebooks and supporting data for one problem set. Open the notebooks in Jupyter and run them from the repository root so that relative data paths resolve correctly. The files are preserved as coursework examples; for a polished reusable implementation, extract the selected method into a small module with tests and a documented API.

## Repository hygiene

Notebook checkpoints and operating-system metadata are ignored by .gitignore. Generated figures, problem statements, and input data remain alongside the exercise that uses them.
